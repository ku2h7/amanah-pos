# Toko Sembako Amanah

Aplikasi manajemen toko sembako berbasis web yang dibangun dengan Next.js 15 dan TypeScript.

## Fitur

- [ ] Manajemen Produk
- [ ] Manajemen Stok
- [ ] Transaksi Penjualan
- [ ] Laporan Keuangan
- [ ] Dashboard Analitik

## Teknologi

- Next.js 15
- TypeScript
- Tailwind CSS
- React Hook Form
- React Query

## Memulai

1. Clone repositori ini
1. Install dependencies:

```bash
yarn install
# atau
npm install
```

1. Jalankan development server:

```bash
yarn dev
# atau
npm run dev
```

1. Buka [http://localhost:3000](http://localhost:3000) di browser Anda

## Struktur Proyek

- `/src/app` - Halaman dan route aplikasi
- `/src/components` - Komponen UI yang dapat digunakan ulang
- `/src/lib` - Utility functions dan konfigurasi
- `/public` - File-file statis
